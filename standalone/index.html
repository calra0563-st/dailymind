구글 스프레드시트 연동 및 배포 안내

구글 스프레드시트의 Apps Script 웹앱 URL을 등록하면 실시간으로 감정이 시트에 저장됩니다.

* URL을 등록하지 않으면 현재 브라우저의 로컬 저장소에 임시 저장됩니다.

📋 구글 스프레드시트 3분 완성 가이드
  1. 새 구글 스프레드시트를 만들고 탭 이름을 '학생명단'과 '감정기록'으로 2개 만듭니다.
    · '학생명단' 탭: 1행에 [번호, 이름] 입력 후 2행부터 학생 목록 입력
    · '감정기록' 탭: 1행에 [일시, 번호, 이름, 감정이모지, 한줄마음] 입력
  2. 상단 메뉴에서 [확장 프로그램] > [Apps Script]를 클릭합니다.
  3. 열린 편집기에 code.gs 파일의 코드를 복사하여 붙여넣습니다.
  4. 우측 상단 [배포] > [새 배포] 클릭 후:
    • 유형: 웹 앱
    • 다음 사용자 권한으로 실행: 나
    • 액세스 권한이 있는 사용자: 모든 사용자(Anyone) (필수!)
  5. 생성된 /exec 로 끝나는 웹앱 URL을 위 입력창에 붙여넣고 [저장하기]를 누르면 완료됩니다!
